## 项目概览

本目录包含我通过 **Dify 低代码平台** 构建的 AI Agent 工作流配置。每个 `.yml` 文件都是一个完整的 AI 应用，包含提示词、工具链和业务逻辑，可直接导入 Dify 使用。

## 🤖 Agent 展示

---

### 🧳 旅游规划助手 (Travel Plans)

**功能定位**: 智能旅行规划与行程管理

| 特性 | 说明 |
|------|------|
| 🔍 **实时搜索** | 接入 Tavily 搜索 API，获取最新旅游资讯 |
| 🗺️ **个性化推荐** | 根据用户偏好生成定制化行程 |
| 📋 **行程输出** | 结构化展示每日行程、预算、注意事项 |
| 🖼️ **多模态支持** | 支持图片上传作为参考 |

#### 工作流架构

```
用户输入 → Tavily 搜索 → LLM 理解分析 → 生成行程 → 返回结果
                     ↑
                     └─ ZhipuAI 大模型驱动
```

#### 典型对话

```
用户：我想去云南旅游，5天4晚，预算3000元，推荐一下行程

AI：
## 🌸 云南5日游行程规划

### Day 1: 昆明
- 游览翠湖公园、云南大学
- 品尝过桥米线
- 住宿：昆明（预算200元）

### Day 2-3: 大理
- 洱海骑行、苍山索道
- 大理古城漫步
- 住宿：大理客栈（预算300元/晚）

### Day 4-5: 丽江
- 丽江古城、束河古镇
- 玉龙雪山一日游
- 住宿：丽江（预算250元/晚）

💰 总预算估算：约2800元（含交通、食宿、门票）
```

### 📊 周报生成器 (MT Weekly Report)

**功能定位**: 自动汇总处理 MT（Machine Translation）翻译周报数据

| 特性 | 说明 |
|------|------|
| 📈 **数据整合** | 自动汇总多来源翻译数据 |
| 📊 **可视化分析** | 生成关键指标统计与趋势图 |
| 📝 **报告生成** | 结构化输出周报文档 |
| 🔄 **自动化** | 定时任务，免手动操作 |

#### 工作流架构

```
原始数据 → 数据清洗 → 指标计算 → 报告生成 → 输出/发送
```

#### 输出报告示例

```markdown
# 📋 MT 周报 (2024-03-25 ~ 2024-03-31)

## 核心指标
| 指标 | 本周 | 环比 |
|------|------|-----|
| 总翻译量 | 125,000 条 | +15% |
| 平均响应时间 | 2.3s | -8% |
| 准确率 | 96.8% | +0.5% |

## 质量问题分布
- 术语不一致: 32%
- 语序调整: 28%
- 漏译: 15%
- 其他: 25%

## 改进建议
1. 完善领域术语库
2. 优化长句拆解策略
...
```

## 🚀 快速开始

### 导入 Dify

1. 打开 [Dify](https://dify.ai/) 平台
2. 进入「工作室」→ 「创建应用」
3. 选择「导入 DSL」功能
4. 上传 `.yml` 配置文件即可

### 配置 API Key

导入后需配置以下密钥：

| 工具 | 用途 | 配置位置 |
|------|------|---------|
| ZhipuAI | 大语言模型 | 环境变量 |
| Tavily | 搜索服务 | 工具配置 |

## 💡 设计思路

### 为什么不直接写代码？

| 对比维度 | 传统开发 | Dify Agent |
|---------|---------|------------|
| **调试周期** | 修改代码 → 部署 → 测试 | 可视化调试，实时生效 |
| **技能门槛** | 需懂编程 | 会写提示词即可 |
| **扩展性** | 依赖开发者能力 | 拖拽节点即可扩展 |
| **协作** | 代码 Review | 工作流可视化，易于团队理解 |

### AI 辅助开发

这些 Agent 的提示词和工作流设计，均由 **Claude Code** 辅助完成：
- 优化提示词结构
- 设计工具调用链路
- 调试输出格式
