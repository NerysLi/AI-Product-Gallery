### 🛩️ 飞机大战游戏 (Plane War)

**技术栈**: Python + Pygame | **开发时间**: ~30 分钟（AI 辅助）

经典街机游戏的完整复刻，包含以下特性：

- 🎮 流畅的键盘操控（方向键移动 + 空格键射击）
- 👾 敌机随机生成与智能移动
- 💥 碰撞检测与爆炸特效
- 📊 实时分数与生命值系统
- ⭐ 连杀加分机制

```
键盘控制：
← → ↑ ↓  : 移动
空格     : 发射子弹
```

**AI 辅助亮点**：
- AI 快速生成完整的游戏框架（类结构、渲染循环、事件处理）
- 边运行边调试，AI 实时定位 bug 并给出修复方案
- 代码注释与逻辑解释清晰，新手也能看懂

```python

        self.y = -50
```

### 🗃️ 海关数据库智能合并系统

**技术栈**: Python + Pandas + pyreadstat | **处理规模**: 2000-2016 年 | **记录数**: 500,000+

用于研究**汇率变动对企业进出口影响**的数据整合工具：

#### 核心功能

| 功能 | 说明 |
|------|------|
| 📂 分块读取 | 50万+ 条记录分块加载，内存占用稳定在 500MB 以内 |
| 🔗 智能匹配 | 自动识别企业名称/邮编+电话等多种匹配字段 |
| 🧹 自动清理 | 每年度合并后自动 GC，内存占用始终可控 |
| 📊 多策略合并 | 优先邮编+电话 → 其次组织代码 → 最后企业名称模糊匹配 |
| 💾 CSV 输出 | 年度独立文件 + 全量汇总，便于后续分析 |

#### 数据规模

```
工业企业数据: 15 个年份文件 (2000-2015)
├─ 单年最大: 923 MB (2010年)
└─ 总记录数: 1000万+ 条

海关进出口数据: 17 个年份文件 (2000-2016)
├─ 单年最大: 362 万条 (2000年)
└─ 总记录数: 5000万+ 条
```

#### 合并结果示例

| 年份 | 匹配记录数 | 匹配方式 |
|------|-----------|---------|
| 2000 | 17,681 | 企业名称 |
| 2002 | 9,742 | 邮编+电话 |
| 2007 | 54,037 | 企业名称 |
| 2013 | 72,333 | 企业名称 |
| **合计** | **537,944** | 多种策略 |

**AI 辅助亮点**：
- 🔍 **数据探索自动化**: AI 分析不同年份的数据结构变化，自动适配字段名
- 🧠 **匹配策略优化**: 从最初的名称匹配 → 迭代为邮编+电话组合 → 最终多种策略加权
- 🐛 **内存优化**: 处理 300万+ 条海关数据时，AI 建议分块读取 + 及时 GC
- 📝 **代码即文档**: 关键函数均有类型标注和中文注释，便于后续维护
